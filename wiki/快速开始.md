# 快速开始

本指南帮助你在 5 分钟内接入 GIM Android IM 客户端 SDK。

## 1. 添加依赖

本工程为扁平单 module 的 Android Library，发布坐标 `io.getbit.gim:gim-sdk-android:1.0.0`。

**方式 A：发布到本机仓库后引入**

```bash
./gradlew publishToMavenLocal
```

```kotlin
// App 模块 build.gradle.kts
repositories {
    mavenLocal()
    google()
    mavenCentral()
    maven { url = uri("https://jitpack.io") }   // LiveKit 依赖的 WebRTC 预编译包
}

dependencies {
    implementation("io.getbit.gim:gim-sdk-android:1.0.0")
}
```

**方式 B：源码 module 依赖**

将本工程作为 submodule 引入，在 `settings.gradle.kts` include 后 `implementation(project(":gim-sdk-android"))`。

> SDK 通过 `api` 传递 WebRTC / Coroutines / Protobuf-javalite / LiveKit，App 侧无需重复声明。

## 2. 声明权限

在 App 的 `AndroidManifest.xml` 中：

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<!-- 音视频通话按需 -->
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />
```

## 3. 创建服务并注册监听

```kotlin
val service = GimImService()

service.addEventListener(object : ImEventListener() {
    override fun onMessageReceived(packet: ImProto.Packet) {
        val msg = PacketCodec.parseChatMessage(packet)
        // 展示 / 落库
    }

    override fun onConnectionStateChanged(state: ImConnectionState) {
        // 更新连接状态指示
    }

    override fun onKicked(code: Int, message: String) {
        // 被顶号，提示并跳转登录
    }
})
```

`ImEventListener` 所有方法均为空实现，只需覆盖你关心的回调。

## 4. 连接（首包认证）

```kotlin
lifecycleScope.launch {
    service.connect(ImConfig(
        host = "192.168.1.100",
        port = 3333,
        userId = "user_001",
        token = "jwt_token",
        device = DeviceType.MOBILE.value,   // "mobile"
        deviceId = persistedDeviceUuid,     // 客户端持久化 UUID，区分同设备重连与异设备顶号
    ))
}
```

连接状态可通过 `StateFlow` 观测：

```kotlin
lifecycleScope.launch {
    service.connectionState.collect { state ->
        // DISCONNECTED / CONNECTING / CONNECTED / AUTHENTICATED / RECONNECTING
    }
}
```

## 5. 发送消息

```kotlin
val packet = PacketCodec.buildSingleChatMsg(
    requestId = UUID.randomUUID().toString(),   // 幂等匹配 ServerAck
    senderId = "user_001",
    receiverId = "user_002",
    contentType = ContentType.TEXT.value,
    content = "Hello GIM!",
    conversationId = "conv_1001_1002",          // 可选
    ext = mapOf("nick" to "Alice"),             // 可选
)
service.send(packet)
```

群聊将 `buildSingleChatMsg` 换成 `buildGroupChatMsg`（`receiverId` 传群 ID）。

## 6. 生命周期联动

```kotlin
override fun onStart(owner: LifecycleOwner) {
    lifecycleScope.launch { service.reconnectIfNeeded() }
}

override fun onStop(owner: LifecycleOwner) {
    service.pauseForBackground()   // 后台切低频重连，省电
}
```

## 7. 断开与释放

```kotlin
lifecycleScope.launch { service.disconnect() }
// 页面彻底销毁时
service.dispose()
```
